# EnigmAgent shared vault core v3

This package contains the authenticated v2 vault format used by the EnigmAgent 3.0.0 gateway, CLI and Node library. It requires Node.js 22 or newer. Legacy v1 vaults are read-only until explicit migration. See the root integrated release documentation for the threat model, migration, backup and recovery rules. The three public core copies and the packaged CLI copy are checked for exact equivalence.
